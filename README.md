# Telegram referral bot

Telegram-бот с реферальной системой, заданиями на подписку, профилем пользователя,
обращениями в поддержку, заявками на вывод и административной панелью.

## Запуск на Railway

Проект собирается из `Dockerfile` и запускается в режиме Telegram long polling.
Веб-порт не нужен. Оставьте один экземпляр сервиса: одновременно должен работать
только один poller для этого токена.

1. Создайте Railway project и разверните этот GitHub-репозиторий как сервис.
2. В настройках сервиса добавьте Variables:
   - `BOT_TOKEN` — токен от `@BotFather`.
   - `ADMIN_IDS` — Telegram ID администраторов, через запятую.
   - `REQUIRED_CHANNEL` — канал, на который нужна подписка (например, `@channel`).
   - `REQUIRED_CHANNEL_URL` — ссылка на этот канал.
   - `REFERRAL_REWARD` — начисление за подтверждённого реферала (по умолчанию `5`).
   - `MIN_WITHDRAWAL` — минимальный баланс для заявки на вывод (по умолчанию `100`).
   - `DATABASE_PATH=/data/bot.sqlite3`.
3. Добавьте Railway Volume с mount path `/data`. Без volume SQLite-файл не будет
   надёжно сохраняться при пересоздании контейнера.
4. Убедитесь, что бот добавлен администратором в обязательный канал и каналы
   заданий, иначе Telegram не даст проверять подписки.
5. После запуска проверьте логи Railway; бот должен сообщить, что запущен в режиме
   long polling.

Не публикуйте настоящий `BOT_TOKEN` в GitHub и не присылайте его в чат. Добавляйте
его только в Railway Variables.

## Локальный запуск

```bash
cp .env.example .env
# Заполните BOT_TOKEN и ADMIN_IDS в .env
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

На Windows активируйте окружение командой `.venv\Scripts\activate`.

## Настройки

По умолчанию за подтверждённого реферала начисляется 5 внутренних баллов, а
минимальная заявка на вывод — 100 баллов. Это не автоматическая выплата: администратор
вручную отмечает заявку выплаченной или отклоняет её в `/admin`. Установите значения
`REFERRAL_REWARD` и `MIN_WITHDRAWAL` в Railway Variables в соответствии с вашими
правилами.

База данных использует SQLite. Для Railway обязательно подключите Volume по пути
`/data` и задайте `DATABASE_PATH=/data/bot.sqlite3`.
